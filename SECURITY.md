# Política de segurança

Este repositório é um laboratório educacional, não uma configuração homologada para produção.

- Não abra RDP (3389) ou SSH (22) para `0.0.0.0/0`.
- Não comite tokens, client secrets, arquivos `.env`, `terraform.tfvars`, state ou planos com informações sensíveis.
- Revise a assinatura, a região, os CIDRs e o plano antes de qualquer `apply`.
- Não use o laboratório para armazenar dados pessoais ou cargas produtivas.
- Não há processo de monitoramento de segurança ou SLA de resposta a incidentes para este projeto.
